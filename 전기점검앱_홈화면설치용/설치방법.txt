[홈 화면 앱 설치 방법] 생산설비 전기부분 유지보수 점검 v2.5

※ 핵심: 홈 화면 앱(PWA)은 파일로 열면 안 되고, 반드시 https:// 주소로 한 번 열어야 합니다.
  이 폴더 전체를 무료 웹호스팅에 올려 주소를 만든 뒤, 폰에서 그 주소를 열어 홈 화면에 추가합니다.

1) 주소 만들기 (둘 중 하나, 3분)
  A. Netlify Drop (가장 쉬움, 가입 없이 가능)
     - 브라우저에서 app.netlify.com/drop 접속 -> 압축 푼 폴더 전체를 끌어다 놓기
     - 나온 https://~.netlify.app 주소 사용
  B. GitHub Pages
     - 새 저장소 만들고 이 폴더의 파일을 모두 올림 -> Settings > Pages > main 브랜치 선택
     - https://아이디.github.io/저장소이름/ 주소 사용

2) 아이폰 (반드시 사파리)
  - 사파리로 주소 열기 -> 하단 공유 버튼 -> "홈 화면에 추가" -> 추가
  - 홈 화면 아이콘으로 실행하면 주소창 없이 앱처럼 열립니다.

3) 안드로이드 (크롬)
  - 크롬으로 주소 열기 -> 우측 상단 ⋮ -> "앱 설치" 또는 "홈 화면에 추가"

4) 주의
  - 앱 데이터는 주소(도메인)별로 따로 저장됩니다. 기존 파일로 쓰던 기록은 새 앱으로 자동 이동되지 않으니,
    기존 앱에서 "사진포함 백업(JSON)" 저장 -> 새 앱에서 불러오기 하세요.
  - 사파리에서 추가한 앱과 사파리 화면의 데이터는 서로 별개입니다. 홈 화면 아이콘으로만 쓰세요.
  - 현장 사각지대에서도 한 번 열어 둔 뒤에는 오프라인 실행됩니다.

5) 앱을 수정해 새 버전을 올릴 때
  - sw.js 맨 위 VERSION 숫자(예: v2.5-1 -> v2.5-2)를 올려서 같이 업로드
  - 폰에서 앱을 완전히 닫았다가 다시 열면 새 버전이 반영됩니다.
